# Data Professional Survey Breakdown

## Overview

This Power BI report provides a breakdown of survey responses from data professionals. It visualizes key insights related to demographics, salaries, job satisfaction, and industry trends.

## Visualizations

- **Treemap**: Distribution of survey takers by country.
- **Stacked Bar Chart**: Avergage salary job title.
- **Cards**:
  - Total number of survey takers by country.
  - Average age of respondents.
- **Donut Chart**: Difficulty of breaking into the data industry.
- **Stacked Column Chart**: Favorite programming languages among respondents.
- **Gauges**:
  - Happiness with salary.
  - Happines with work-life balance.

## Key Insights

- Identufy the top countries contributing to the survey.
- Compare average salaries across different job titles.
- Understand the challenges professionals face when entering the data field.
- Discover popular programming languages in the industry.
- Assess overall satisfaction with salary and work-life balance.

## Usage

Open the `.pbix` file in Power BI to explore the interactive visualizations and gain insights into the data professional landscape.
